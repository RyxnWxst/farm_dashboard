# Farm Dashboard

JavaFX Farm dashboard.

## Requirements
- JDK 17
- Maven (built into IntelliJ and Eclipse)

## Run
- IntelliJ: Maven tool window > Plugins > javafx > `javafx:run`
- Terminal: `mvn clean javafx:run`

## Test
- IntelliJ: Maven tool window > Lifecycle > `test`
- Terminal: `mvn clean test`
